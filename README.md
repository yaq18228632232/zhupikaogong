# 朱批书房 · 公考学习站

一个纯静态的个人公考学习网站：行测刷题（内置 210 题 + 可加载 24,886 道历年真题）、135 题模拟考试、错题本与统计、申论学习、写作练习与 AI 批改、在线题库入口、实时时政热点、考公资源导航，以及上海交通大学常用网站入口。支持上传 PDF / Word / 文本生成题库，也支持接入大模型（如 DeepSeek）根据材料出题、批改申论。

无需服务器、无需安装环境，所有学习数据保存在浏览器本地，可随时导出备份。

---

## 一、本地打开

**方式一（最简单）**：直接双击 `index.html`，用 Chrome / Edge 打开。刷题、申论、时政、资源导航等功能都能用；扩展真题题库会通过脚本方式加载（首次约 70MB），PDF/Word 解析、时政抓取和大模型调用需要联网。

**方式二（推荐，功能最完整）**：在本目录打开命令行，运行

```bash
python3 -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`。关闭命令行窗口即停止。Mac 自带 python3；Windows 可安装 Python 或在目录里运行 `py -m http.server 8080`。

## 二、部署到 GitHub Pages（免费）

### 1. 注册 / 登录 GitHub

没有账号的话先在 https://github.com 注册（免费）。

### 2. 新建仓库

右上角 **+ → New repository**：

- Repository name 填 `zhubi-study`（或任意名字）
- 选择 **Public**（免费账号的 Pages 需要公开仓库）
- 不要勾选 "Add a README file"
- 点击 **Create repository**

### 3. 上传网站文件

在新建的仓库页面点击 **uploading an existing file**，把本文件夹里的**所有内容**（`index.html`、`css`、`js`、`README.md`、`.nojekyll`）拖进去，点 **Commit changes**。

> 注意：要上传文件夹里面的文件，而不是把 `zhubi-study` 文件夹本身再套一层。上传后仓库根目录应能直接看到 `index.html`。

也可以用命令行：

```bash
cd 本文件夹所在路径
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/你的用户名/zhubi-study.git
git push -u origin main
```

### 4. 开启 Pages

仓库页面 **Settings → Pages**：

- **Source** 选择 **Deploy from a branch**
- **Branch** 选择 `main`，目录选择 `/ (root)`
- 点击 **Save**

等待 1—2 分钟，访问：

```
https://你的用户名.github.io/zhubi-study/
```

以后更新文件，重新上传 / push 即可，Pages 会自动重新发布。

### 5. 国内网络提示

GitHub Pages 在国内访问速度和稳定性一般，偶尔需要多刷新几次。如果体验不好，可以把同样的文件部署到：

- **Cloudflare Pages**（免费、国内访问通常较稳）
- **Vercel**（免费，绑定域名方便）
- 自己的服务器（把文件放到任意静态目录即可，如 Nginx）

网站是纯静态文件，放到任何支持静态托管的平台都能直接运行。

> **关于扩展真题题库**：`js/data/packs/` 里的 1.6 万道真题仅供个人学习使用，**不要上传到公开仓库或公开网站**。公开部署时请删除该目录（网站会自动退回内置 210 题），或在设置中关闭扩展题库。`.gitignore` 已默认排除该目录。

## 四、题库导入

### 1. 文件解析导入

支持格式：

- **PDF**（文字版；扫描版 / 图片版没有文字层，无法直接解析，需要先 OCR）
- **Word `.docx`**（旧版 `.doc` 请先在 Word 中另存为 `.docx`）
- **TXT / Markdown**

推荐排版（越接近越准确）：

```
1. 我国第一部纪传体通史是（ ）
A. 《春秋》
B. 《史记》
C. 《汉书》
D. 《资治通鉴》
答案：B
解析：《史记》是司马迁所著的第一部纪传体通史。

2. 下列属于扩张性货币政策的是（ ）
A. 提高存款准备金率
B. 降低存款准备金率
C. 增加税收
D. 减少财政支出
答案：B
解析：降低存款准备金率会释放流动性。
```

解析后的流程：识别 → 预览校对（可改模块、补答案、勾选）→ 导入题库。缺答案、缺选项的题目会被标出，不会静默导入。

也支持文末统一答案，如 `1—5 ABCDA`、`6.C 7.A`。

### 2. AI 出题

在 **设置 → AI 出题接口** 中填写：

- 接口地址：`https://api.deepseek.com/v1`（默认）
- API Key：你的 DeepSeek Key（只保存在本机浏览器）
- 模型：`deepseek-chat`

然后在 **题库导入 → AI 出题** 粘贴学习材料，选择题量，点击“生成题目”，校对后导入。

**如果浏览器直连失败**：部分服务商不允许浏览器跨域调用（CORS），此时使用页面下方的兜底方式——点“复制提示词”，粘贴到任意大模型对话里，再把返回的 JSON 粘贴回来解析。该方式不受跨域限制。

> AI 生成的题目可能有事实错误或答案偏差，务必逐题校对后再导入。

### 3. 导入题库管理

“题库导入 → 我的题库”可以查看、删除导入的题目，或导出题库 JSON。导入的题目会自动参与刷题和模拟考试；题库超过 135 题后，模拟卷会按模块配额随机抽题组卷。

### 4. 从链接更新题库

“题库导入 → 我的题库”提供 **从链接更新题库**：填入一个返回 JSON 的网址（GitHub Raw、Gist、自己的静态服务器均可），网站会获取题目、按题干去重后合并到“我的题库”，可以反复更新。

格式示例：

```json
[
  {
    "module": "常识判断",
    "stem": "题干……",
    "options": ["A 选项", "B 选项", "C 选项", "D 选项"],
    "answer": 0,
    "explain": "解析……"
  }
]
```

`answer` 写下标（从 0 开始）或 A/B/C/D 均可；`module` 可写模块 id 或中文名。目标网址需要允许跨域访问（GitHub Raw、Gist 默认支持）。

### 5. 题库会“用完”吗？

不会。站内题库现在有 210 题，练习与模考的换题机制是：

- 练习每组 20 题，按“没做过 → 错题本中久未复习 → 最久没做”的顺序出题，每次“再来一组”都会优先换新题；全部做过一轮后，会从最久没做的题重新轮换。
- 模考每次从题库中抽取 135 题，并优先避开上一套已考题目，两套卷子之间只有部分重叠。
- 想继续扩充：可以上传 PDF/Word 导入、让 AI 出题，或用上面的“从链接更新题库”合并外部题库。

### 6. 扩展真题题库（24,886 道，含图片题）

网站附带一个 **24,886 道历年行测真题**的扩展题库包，位于 `js/data/packs/`，题目约 42MB、配图约 29MB（图片按需加载）：

- 覆盖 2016—2026 年国考、省考、选调等试卷，每题带年份/地区标签和解析；图形推理、资料分析等题目会直接显示原题图片；
- 打开网站时自动加载（显示进度），加载完成后练习、模考、统计都会使用这 1.6 万道题；
- 通过本地服务器访问时读取 JSON 题库包；直接双击 `index.html`（file://）时自动改用 JS 题库包，两种方式都能加载；
- 可在 **设置 → 扩展真题题库** 中关闭；关闭或加载失败时自动使用内置 210 题；
- 题库包是静态文件（同一份数据提供 JSON 和 JS 两种格式），只加载到内存，不占用 localStorage。

**来源与使用范围**：题目来自开源项目 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)，经 [GongkaoNaoku](https://github.com/jangviktor-web/GongkaoNaoku) 去重整理。代码采用 Apache-2.0 许可；**真题版权归原作者及原题库平台所有，仅供个人学习使用，请勿公开传播或上传到公开仓库**。项目已通过 `.gitignore` 默认排除 `js/data/packs/`；如果要公开部署，请删除该目录或在设置中关闭扩展题库。

**图形题显示不出来怎么办？** 扩展题库已包含图形推理、资料分析等题目的原题配图，图片单独存放在 `js/data/images/`，按需加载。若图片不显示，请确认该目录完整，并按 `Ctrl + F5` 强制刷新。

## 五、申论 AI 批改与在线题库

### 1. 申论 AI 批改

写作练习区分小题和大作文，共 26 道题，覆盖归纳概括、综合分析、提出对策、贯彻执行、文章写作五种题型，字数要求不同：

- **小题**（归纳概括、综合分析、提出对策、贯彻执行）：一般 200—400 字；
- **文章写作（大作文）**：一般 1000 字左右，练习按“800—1000 字”要求；
- 写作练习默认打开大作文，题目列表里会标注每道题的字数要求；字数超出时输入框下方会提示。

完成作答后，点击 **开始批改**：

- 按题型使用不同的评分维度（归纳概括：要点全面 / 准确提炼 / 条理清晰 / 语言简练；提出对策：针对性 / 可行性 / 具体性 / 条理；文章写作：立意 / 结构 / 论证 / 语言等），给出 0—100 的模拟分数。
- 输出各维度得分与点评、优点、问题、改进建议、总评和修改示范。
- 批改结果保存在本机，切换题目后可回来查看；修改作答后会提示“建议重新批改”。
- 页面同时显示基础检查：字数是否达标、段落数、分条 / 分论点标记数量。

AI 批改使用 **设置 → AI 出题接口** 中配置的大模型（如 DeepSeek）。如果没有配置 Key 或浏览器直连被跨域限制拦截，可以：

1. 点击 **复制批改提示词**；
2. 粘贴到任意大模型对话中；
3. 把返回的 JSON 粘贴到“手动批改”框，点击 **解析并保存评分**。

> AI 评分是模拟估分，用于发现结构和表达问题，不能替代老师阅卷，也不要把它当作真实考试分数。

### 2. 在线题库入口

行测刷题页下方提供外部题库入口：粉笔题库、华图在线题库、中公题库、半月谈。

两种题库建议这样配合：

- **站内题库**：每日练习、135 题模考、错题本与正确率统计，数据全部在本机，离线可用。
- **外部题库**：题量更大、有万人模考和直播解析，但需要各自登录，做题数据不与本站互通（受跨域、登录和版权限制，无法自动同步）。

以站内为主、外部为辅；外链地址可在 `js/data/kaogong.js` 的 `ONLINE_BANKS` 中修改。

## 六、时政热点与提醒

### 数据来源

内置两个官方 RSS 源（可在 `js/data/kaogong.js` 中修改）：

- **中新网 · 即时新闻**：综合时政、经济、社会新闻，更新频繁
- **中国政府网 · 政策发布**：国务院政策文件、规划与批复，适合申论政策积累

页面同时提供人民网、新华网、求是网、半月谈、央视网等官方入口，可直接跳转浏览。

### 刷新与“推送”机制

纯静态网站无法在浏览器关闭后推送通知，这里采用最接近的方案：

1. 打开“时政热点”页时自动刷新一次，之后页面打开期间**每 15 分钟自动检查更新**；
2. 发现新内容时，左侧“时政热点”菜单会显示**未读数量角标**，首页“今日时政”同步展示最新头条；
3. 可在时政页点击 **开启桌面提醒**，授权后新热点会弹出系统通知（浏览器需保持打开）。

### 抓取方式与限制

浏览器直接访问 RSS 会遇到跨域限制，因此页面会依次尝试：

1. `rss2json.com`（把 RSS 转成 JSON，支持跨域）
2. `allorigins.win`（代理原始 XML，支持跨域）
3. 都失败时显示缓存内容，并提供官方来源链接

如果所在网络无法访问这些公共服务，页面会提示“获取失败”，此时直接点击官方来源即可，不影响其他功能。新闻标题和摘要会缓存到本机，断网时仍可查看上次内容。

## 八、数据存储与备份

- 学习数据保存在浏览器的 **localStorage**（键名 `zhubi_study_v1`），时政缓存使用 `zhubi_news_cache_v1`，均不上传服务器。扩展真题题库是静态文件，只加载到内存，不写入 localStorage。
- **清除浏览器数据、使用无痕模式、换浏览器或换设备都会丢失记录**。
- 在 **设置 → 数据备份**：
  - **导出备份 JSON**：下载完整数据（作答记录、错题、考试、申论草稿、导入题库、设置）；
  - **导入备份**：用备份文件覆盖当前数据；
  - **清空所有数据**：重置（主题保留），操作前请先导出。
- 浏览器 localStorage 一般有 5MB 左右上限，正常使用足够存几千道题；若保存失败，页面会提示，建议先导出再清理。

常见修改：

- **加内置题**：在 `js/data/questions.js` 的 `questions` 数组里复制一条，修改 `id`（唯一）、`module`（`changshi` / `yanyu` / `shuliang` / `panduan` / `ziliao`）、`stem`、`options`、`answer`（从 0 开始）、`explain`。需要表格的题干加 `html: true` 并使用简单 `<table>`。
- **改模考结构 / 时长**：`js/exam.js` 顶部 `FULL_COUNT`、`FULL_MINUTES`、`QUOTAS`（各模块配额）。默认按国考副省级 135 题、120 分钟。
- **换时政源**：`js/data/kaogong.js` 中的 `NEWS_SOURCES`，填写任意 RSS 地址。
- **改主题色**：`css/style.css` 顶部 `:root[data-theme="crimson"]` 等变量。
- **改交大链接 / 考公链接**：`js/data/sjtu.js`、`js/data/kaogong.js`。
- **改申论内容**：`js/data/shenlun.js`（方法、素材、范文、模拟练习均可加）。

## 十、常见问题

**打开后页面空白 / 样式丢失？**
确认 `css`、`js` 文件夹和 `index.html` 在同一目录，且都已上传。GitHub Pages 上请确认仓库根目录能直接看到 `index.html`。

**为什么模考是 135 题？**
国考副省级行测为 135 题、120 分钟；本网站内置题库也按 20/40/15/40/20 的模块结构配到 135 题。导入题库超过 135 题后，会按该结构随机抽题；不足 135 题时会按现有题量组卷并提示。

**时政页显示“获取失败”？**
RSS 抓取依赖 `rss2json.com` / `allorigins.win` 两个公共服务，部分网络环境可能访问不了。页面会保留上次缓存，并给出官方来源链接，可直接点击浏览。若有自己的 RSS 代理，可修改 `js/news.js` 中的抓取地址。

**桌面提醒没有弹出？**
需要在时政页点击“开启桌面提醒”并允许浏览器通知；浏览器必须保持打开（纯静态网站无法在关闭后推送）。

**PDF 提示“未提取到有效文字”？**
大概率是扫描版 PDF（每页是图片），需要先用 OCR 工具转成文字版，或改用 Word / 文本。

**上传 PDF / Word 没反应？**
解析库（pdf.js、mammoth）从 CDN 加载，需要联网；网络不通时请改用“粘贴文本解析”。

**AI 出题报网络错误？**
多为服务商 CORS 限制或地址填错。改用“复制提示词 + 粘贴 JSON”的兜底方式即可。

**站内题库只有 135 道、做完就没题了吗？**
不是。内置 210 题，加上扩展真题共 25,096 题；模考按国考标准每次抽 135 题，练习每组 20 题并优先出没做过的题，模考优先避开上一套。题库还可以通过导入文件、AI 出题或“从链接更新题库”继续扩充。

**为什么扩展题库加载慢 / 加载失败？**
题库包约 70MB（题目 42MB + 配图 29MB，图片按需加载），首次打开需要加载并解析，本地文件通常 1—2 秒，网络部署会慢一些。加载失败时网站会自动使用内置 210 题；也可在设置中关闭扩展题库。若双击打开时仍失败，可改用本地服务器方式访问。

**双击 index.html 能加载扩展题库吗？**
可以。直接打开时网站会自动用脚本方式读取题库包，不需要服务器；如果浏览器有限制或文件不完整，会退回内置题库并提示。

**图形题、资料分析图能显示吗？**
可以。扩展题库已包含图形推理和资料分析的原题配图，图片按需加载；如果图片不显示，请确认 `js/data/images/` 目录完整，并强制刷新页面。

**为什么有的题只要求 200 字？**
那是申论小题（归纳概括、提出对策等）的字数要求，小题通常 200—500 字；大作文国考多为 1000—1200 字，省考、联考多为 800—1200 字。写作练习默认打开的是大作文，题目列表里每道题都标注了对应字数。

**申论真题的给定材料为什么比我手上的短？**
真题原文资料通常 6000—8000 字，站内收录的是按案例与要点整理的“梗概版”，作答要求（题型、分值、字数）保留真题原貌，适合练审题、练结构、练分条。冲刺阶段建议另找完整真题原文，限时 150 分钟整套作答。

**申论批改提示“尚未配置大模型”/批改失败？**
先在 **设置 → AI 出题接口** 填写地址与 Key（DeepSeek 可用 `https://api.deepseek.com/v1`、模型 `deepseek-chat`）。如果仍然失败，通常是浏览器跨域限制：在批改卡片中点击“复制批改提示词”，粘贴到大模型对话，再把返回的 JSON 粘贴回“手动批改”即可。

**在线题库的做题记录能和本站同步吗？**
不能。外部题库受跨域、登录和版权限制，无法自动同步数据；外链只用于扩充练习量。本站的统计和错题本只记录站内做题。

**换电脑后记录没了？**
数据只在本机。请在旧设备“设置 → 导出备份”，在新设备“导入备份”。

**交大网站打不开 / 需要登录？**
入口只是链接。先在教学信息服务网或交我办登录一次，浏览器会记住登录状态；部分系统要求校园网或 VPN。
